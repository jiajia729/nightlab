# 夜間實驗室 v2 設計文件（2026-10-08 與使用者討論定案）

使用者：梁哲嘉（師大化學系），用繁體中文溝通。主要在 Galaxy Tab S11（Chrome）玩，以 PWA 安裝（https://jiajia729.github.io/nightlab/）。

## 目標
把 v1（無限關卡 roguelike）改成**可以玩 90–120 分鐘才破關的完整遊戲**，另有沙盒模式。之後可能上架 itch.io（自由付費）。

## 模式
1. **故事模式（關卡模式）**：約 6 章、40–50 關，每關 2–3 分鐘。
   - 每關三顆星（例如：過關、分數 ≥ X、額外條件）。星星數達標才開下一章，可回頭重玩。
   - 失敗只重試該關，不從頭。
   - 故事：最輕量即可——每章開頭 2–3 句「實驗筆記」介紹本章內容，不做劇情（使用者說「可有可無」）。
2. **沙盒模式**：全部元素、全部儀器、無回合限制、溫度/火花/儀器無限使用，純粹實驗反應。可清空燒杯、可直接放任何分子（不受反應台限制，或反應台可自選原子）。
3. **無限挑戰**：保留 v1 的補給＋升級 roguelike 玩法（使用者沒特別要，但現有，保留當額外模式即可，低優先）。

## 關卡類型（混合，避免每關一樣）
- 湊分數（v1 玩法）
- 合成任務：「做出 2 個 H₂SO₄」「收集 3 次 NaCl」
- 限制關：不能用火花、溫度固定、反應台只有 5 格、回合很少
- 謎題關：燒杯預先擺好分子，用最少步數觸發連鎖（有固定解，需驗證可解）
- 關主關：每章最後一關，綜合該章機制

## 儀器（使用者特別要求：「迴旋濃縮、簡單蒸餾，還有雜七雜八的」）
做成會改變玩法的工具，照真實用途設計；故事模式隨章節解鎖、有次數，沙盒無限。
| 儀器 | 效果 | 原理 |
|---|---|---|
| 簡單蒸餾 | 選一欄，把沸點最低的液體蒸出收集得分 | 依沸點分離 |
| 迴旋濃縮 | 整杯低沸點溶劑（如 bp < 100 °C 的液體）一次抽走得分 | 減壓降低沸點 |
| 過濾 | 濾出某一列（或全部）固體/沉澱收集 | 固液分離 |
| 分液漏斗 | 互換上下兩層液體 | 依密度分層 |
| 電解槽 | H₂O → H₂ + O₂；熔融 NaCl → Na + Cl₂ 等 | 電化學（使用者研究興趣之一） |
| 乾燥管 | 吸掉杯中全部水 | 乾燥劑 |
| 紫外燈 | 觸發自由基反應（甲烷氯化等），取代 v1「火花」的光照部分 | 光化學 |
| 觸媒（Fe、Ni、Pt、V₂O₅） | 讓工業反應在較低溫度發生 | 降低活化能 |
| 離心機 | 整欄依密度重新排列 | 離心分離 |
| 冰浴、油浴 | 更細的溫度段 | 溫控 |
（可再加：研缽、滴定管、本生燈、焰色反應用白金絲等，自行判斷。）

## 元素（使用者：「能加多少就多少」）
從 v1 的 10 種（H C N O F Na Mg S Cl Ca）擴充到約 22 種：Li、B、Al、Si、P、K、Mn、Fe、Cu、Zn、Br、Ag、I、Ba（Be 可略）。
目標約 180 種物質、300+ 條反應。視覺亮點：
- 沉澱顏色：AgCl 白、AgBr 淡黃、AgI 黃、Cu(OH)₂ 藍、Fe(OH)₃ 紅棕、BaSO₄ 白
- 有色物質：KMnO₄ 紫、CuSO₄ 藍、Br₂ 紅棕液體、I₂ 紫黑固體／紫色蒸氣
- 焰色反應：Na 黃、K 紫、Cu 綠（可做成儀器或特效）
品質要求：所有方程式由程式自動配平並測試；熔沸點、自燃溫度、分解溫度用真實數據；簡化之處（觸媒、高壓、部分分解產物）在規則頁註明。

## 保留 v1 的優點
互動教學、下一步提示列（可關）、選取高亮、新元素開場提示、圖鑑、夜間實驗室配色（深墨藍＋CPK 原子色＋鈉燈琥珀）、平板/手機版面、離線 PWA。

## 執行方式（分階段，每階段 git commit 並推到 GitHub）
1. 引擎：儀器機制、目標類型、星星、模式切換
2. 化學資料：新元素/物質/反應，全部測試
3. 關卡：6 章 ~45 關，用電腦玩家（test/bot.js）校準到 90–120 分鐘破關；謎題關驗證可解
4. 沙盒模式
5. 測試（Node 單元測試＋Playwright 截圖平板 1280×720、800×1220、手機 412×860）並發佈 PWA

一晚做不完是正常的：優先順序 1 → 2 → 前兩三章可玩 → 其餘章節 → 沙盒。每階段完成都要能玩、能推上去。
